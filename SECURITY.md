# Security

Please report security issues privately, not in a public issue.

- **[Report a vulnerability privately](https://github.com/5DHelLD5/dynamic-audio-releases/security/advisories/new)**. This opens an advisory that only you and the author can see.

Please include:

- what the issue is and what an attacker could do with it;
- steps to reproduce or a proof of concept;
- your Dynamic Audio version (Settings → About) and macOS version.

## What to expect

- Dynamic Audio is made by one person, so please allow reasonable time for a reply and a fix.
- Please wait for the fix to ship before you talk about the issue in public.
- If you want credit, you will get it in the release notes.

Only the latest release gets fixes. The app installs updates itself, and only when the update is signed by the author.

## По-русски

Об уязвимостях сообщайте приватно по ссылке выше, а не в открытом issue. Укажите, в чём проблема, как её повторить, и версии Dynamic Audio и macOS.
